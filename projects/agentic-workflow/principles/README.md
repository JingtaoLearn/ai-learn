# Agentic Workflow Principles

This directory contains the shared judgment layer for every Product Agent Suite.

1. [`HARD_BOUNDARIES.md`](HARD_BOUNDARIES.md) — non-overridable safety, truth, and authority rules.
2. [`DEFAULTS.md`](DEFAULTS.md) — cross-product defaults for choosing useful, evidence-backed Actions.
3. [`RESOLUTION.md`](RESOLUTION.md) — authority, inheritance, conflicts, revision binding, and completion receipts.
4. [`roles/`](roles/) — professional judgment for each stable Role.

The files define how Agents choose; they do not prescribe a fixed workflow. Product-specific value and evidence rules belong in each product's `PRINCIPLES.md`. Task scope and Validation belong in its Handoff.
