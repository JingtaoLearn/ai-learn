# Agentic Workflow Templates

These templates are maintained by `AgenticWorkflow-Assistant` and instantiated per product only after the product Goal, Principles, safety boundary, and observed role needs are known.

- [`AGENTIC_WORKFLOW_ASSISTANT.md`](AGENTIC_WORKFLOW_ASSISTANT.md) defines the global flow-maintainer role.
- [`PRODUCT_AGENT_SUITE.md`](PRODUCT_AGENT_SUITE.md) defines one isolated product Agent suite, its persistent Owner Session, model policy, Signal path, and Handoff contract.
- [`PRODUCT_COMMUNICATION.md`](PRODUCT_COMMUNICATION.md) defines the private Feishu product group, native route, prompt-first behavior, and provisioning acceptance.
- [`PRODUCT_GROUP_REGISTRY.md`](PRODUCT_GROUP_REGISTRY.md) defines the private local binding index without committing live identifiers.

Templates describe native Hermes resources. Applying one to live Profiles, permissions, schedules, production, merge, deployment, paid, or public state still follows the existing authorization boundary.
