# Framework scope

This checkout versions the Agentic Workflow framework: code, reusable prompts,
principles, templates, assets, procedures and their changes. It is not an active
product runtime, execution store, or live-status dashboard.

The V2 design uses AI judgment and supported Hermes native capabilities. Product
Owners remain accountable for coherent Outcomes and choose direct execution or
delegation. The Assistant maintains suite form and framework conformance.

Concrete group, Session, task, experiment, deployment and observation state lives
in the installed Hermes/product environment, not in this framework source tree.
Historical runtime snapshots formerly committed here remain in Git history;
they are not instructions to restore an old suite.

GitHub Issues and PRs remain valid collaboration and delivery tools. Products
such as QuantResearch continue to change and version their own application code.
The repository boundary does not prohibit product development or issue tracking.

Read [VALIDATION.md](VALIDATION.md) for the real-product acceptance protocol and
[REPORTING.md](REPORTING.md) for user-facing reports and discussion.
