# Agent Engineering Configuration

This directory contains repository-level configuration consumed by the Matt Pocock engineering workflow.

- [`issue-tracker.md`](issue-tracker.md) defines where specs and tickets live.
- [`triage-labels.md`](triage-labels.md) maps canonical workflow roles to GitHub labels.
- [`domain.md`](domain.md) defines how agents discover context glossaries and ADRs.

Product requirements and implementation plans belong in their project contexts, not here.
